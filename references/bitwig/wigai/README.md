# WigAI reference

Third-party Bitwig extension that embeds an MCP server.

- **Project:** https://github.com/fabb/WigAI
- **Pinned version:** 0.10.1
- **Release:** https://github.com/fabb/WigAI/releases/tag/0.10.1

## Install

Copy `WigAI-0.10.1.bwextension` to:

```
%USERPROFILE%\Documents\Bitwig Studio\Extensions\WigAI.bwextension
```

Enable in Bitwig, then use the project MCP config at `./.cursor/mcp.json`.

Setup details: [`../../../docs/wigai-setup.md`](../../../docs/wigai-setup.md)
